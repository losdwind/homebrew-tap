# Homebrew Tap for UnimeType

Official [Homebrew](https://brew.sh) tap for **[UnimeType](https://unimetype.com)** (`v1.0.22`) — a native macOS (`InputMethodKit`) multilingual input method that lets you type mixed-language sentences (Pinyin, Romaji, Hinglish, Arabizi, Russian Translit + English) on a standard Latin keyboard and convert them in one action while preserving English words, code identifiers, and URLs.

## Install on macOS

```bash
brew tap losdwind/tap
brew install --cask unimetype
```

After installation, launch **UnimeTypeMac.app** from `/Applications` to enable the **UnimeType** input source in `System Settings → Keyboard → Input Sources`.
